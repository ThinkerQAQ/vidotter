VidOtter · 安装浏览器扩展

本地 Bridge 已安装。要在浏览器网页里发现视频并下载，还需要启用 VidOtter 扩展。这是首次使用的必要步骤，不需要扩展商店或额外下载。

  1. 安装向导会尝试打开浏览器的扩展管理页面和本机的 extension 文件夹（点击打开）。
  2. 点击上述链接可直接打开本地扩展文件夹；若浏览器管理页没有自动打开，请在 Edge 地址栏输入 edge://extensions；Chrome 输入 chrome://extensions。
  3. 开启开发者模式。
  4. 点击加载解压缩的扩展（Load unpacked）。
  5. 选择extension 文件夹（点击打开），也就是直接包含 manifest.json 的目录。
  6. 找到 VidOtter 扩展并固定到浏览器工具栏。打开扩展，检查是否已连接本地 Bridge。

注意： 浏览器要求你本人确认加载本地扩展，安装器不能绕过该授权。首次安装后请保留原本的安装目录，升级时也不要删除 Data。

English — browser extension activation

  1. Setup opens the browser's extension manager and the installed extension folder (open).
  2. Or type edge://extensions (Edge) or chrome://extensions (Chrome) in the address bar.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the extension folder containing manifest.json.
  5. Pin VidOtter and open it to confirm the local Bridge connection.
VidOtter is distributed without browser store publication. This guide is available offline.
