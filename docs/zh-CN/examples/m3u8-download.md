# 示例：下载一个有限时长的 HLS 视频

使用自己控制或有权保存的视频页。本例假设视频为有限时长、无 DRM 的 HLS，且 FFmpeg 可用；不保证能录制无限直播流。

## 选择播放清单

1. 打开页面并播放，再打开 VidOtter 的资源嗅探。
2. 查找 `.m3u8`。主清单列出画质版本，媒体清单列出分片；它们都不同于单个 `.ts` 或 `.m4s` 分片。
3. 排除广告，选择目标视频。出现多个清晰度时，核对 URL、标题，或在下载设置中选择需要的高度。
4. 本例不下载字幕，只提交一次。若出现网页播放列表对话框，不想整组下载时选择当前视频。网页播放列表表示多个视频，HLS 清单表示分片、画质，两者不同。

## 检查结果

在下载任务中观察下载及后续封装。完成后打开 MP4，确认画面和声音，跳到接近结尾的位置，核对时长。只有首个分片能播放，不代表完整视频已保存。

请求过期时先打开、播放来源，再刷新检测或会话后恢复。缺少 FFmpeg 属于工具问题，403 可能是会话缺失或过期，分片失败也不会通过修改字幕解决。见[故障排查](../how-to/troubleshoot.md)与[恢复](../how-to/manage-downloads.md)。
