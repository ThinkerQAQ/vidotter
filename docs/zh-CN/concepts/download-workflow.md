# 从检测到输出文件

1. **检测**：扩展观察页面请求和媒体元素。先播放，再查看资源列表；单个分片不是完整视频。
2. **解析**：Bridge 选择直链，或调用 yt-dlp 处理支持的网页、分离音视频来源。此阶段可能需要浏览器授权或选择播放列表。
3. **下载**：Worker 获取文件、分片，并将支持的检查点保存在 `Data/work/`。
4. **封装**：桌面端按需通过 FFmpeg 合并或重新封装。Android 使用系统封装器，支持的格式范围更窄。
5. **字幕**：按所选模式下载原站字幕或进行本地识别；指定输出语言后再翻译。
6. **输出**：以完成任务的文件为准。媒体下载完成时，字幕可能仍在处理中。

检测到资源、提交成功、任务完成是三个不同结果。URL 过期可能使已检测到的资源下载失败；缺少模型也可能在媒体下载后导致字幕阶段失败。

暂停会保留支持恢复的工作文件，继续下载取决于检查点和来源当前是否可访问。删除任务记录与删除输出文件是独立选项，见[任务管理](../how-to/manage-downloads.md)。
