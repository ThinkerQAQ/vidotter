# 下载字幕、本地识别与翻译

在“资源嗅探”页为本次下载选择字幕。界面语言位于“设置 → 界面与交互”，与视频语言、字幕语言独立。

## 选择字幕来源

| 检测页选项 | 行为 | 依赖 |
| --- | --- | --- |
| 不下载字幕 | 只下载媒体 | 媒体来源需要的工具 |
| 原站中文 / 原站英文 | 请求对应语言，包含自动字幕 | yt-dlp 和支持的来源 |
| 全部原站字幕 | 请求可用原站语言 | yt-dlp 和支持的来源 |
| 原站优先，无字幕时本地识别 | 先找字幕，没有时再识别 | yt-dlp；回退识别需要 FFmpeg、whisper.cpp 和模型 |
| 始终使用本地语音识别 | 识别下载媒体中的语音 | FFmpeg、whisper.cpp 和模型 |

仅选原站字幕不会自动启动本地识别。媒体直链不一定包含原站字幕信息，获取原站字幕需要能解析对应来源页面。

## 生成本地字幕

1. 在[工具设置](configure-tools.md)确认 FFmpeg、whisper.cpp 和所选模型可用。
2. 返回“资源嗅探”，选择本地识别或原站优先模式。
3. 选择“视频语音”；不翻译时也可使用自动检测。
4. 仅转录时保持输出语言不变，再提交下载。
5. 在“下载任务”查看音频处理、识别及字幕阶段，并检查媒体旁生成的字幕文件。

## 翻译或生成双语 SRT

1. 确认 llama.cpp 和所选翻译模型可用。
2. 选择字幕来源，再选择简体中文、英语等“输出语言”。
3. 涉及本地识别时，必须明确选择“视频语音”。识别后翻译不接受自动检测语音语言。
4. 选择“仅译文”或“原文 + 译文”。双语字幕保留原文，下一行加入翻译。
5. 等待模型加载和翻译完成；媒体下载结束不等于字幕已经处理完。

生成的翻译、双语字幕采用 SRT；原站字幕可能保留来源格式。使用前抽查几处时间戳和文字，确认识别、翻译质量。

失败时先区分缺少程序、缺少模型、模型下载失败、原站没有字幕或翻译失败，再按[故障排查](troubleshoot.md)处理，避免重复提交同一下载。
