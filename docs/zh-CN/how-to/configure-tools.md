# 配置下载工具与模型

先完成一次[不带字幕的下载](../tutorial/first-download.md)，再打开“设置 → 下载能力”，确认各工具状态后启用对应功能。

| 工具 | 用途 | 发行包提供方式 |
| --- | --- | --- |
| Go 下载器 | 媒体直链、HLS 下载 | Bridge 内置 |
| FFmpeg | 封装、音视频合并、识别前音频处理 | Windows 附带 Slim；Linux/macOS 单独安装 |
| yt-dlp | 支持的网页解析、原站字幕 | 在设置中按需下载安装 |
| whisper.cpp | 本地语音识别 | Windows 附带 CPU CLI 与依赖库，模型另下载 |
| llama.cpp | 本地字幕翻译 | Windows 附带 CPU Server 与依赖库，模型另下载 |

## 下载目录与网络

1. 选择可写的输出目录，默认位于安装目录的 `Data/downloads/`。
2. 下载并发范围为 1–64，默认 12。它是下载器并发参数，不代表一定同时运行这么多个任务。
3. 初次保持自动画质，也可选择 `best` 或 `720` 等高度。可用画质取决于来源，指定高度不可用时可能回退到其他版本。
4. 需要代理时再启用，填写实际地址、保存，然后测试一个任务。浏览器能联网，不代表 Bridge 或组件下载器使用了同一条网络路径。

## 可执行文件路径

设置中明确填写的路径优先。如果指向不存在的文件，需要修正或清空，Bridge 不会自动忽略错误覆盖项。自动查找依次检查可执行文件、安装目录附近的工具位置、`Data/tools/` 下载工具和 PATH。whisper.cpp、llama.cpp 的运行库需要保留在各自子目录内。

Linux/macOS 可通过系统包管理器安装 FFmpeg，也可指定已有程序。如果 Bridge 启动后才修改 PATH，需要重启并刷新工具状态。FFmpeg Slim 面向本应用的媒体流程，不能当作完整通用版 FFmpeg 使用。

## 安装可选组件

yt-dlp：打开对应工具卡片，使用安装操作。程序下载上游发行资产并核对校验和，完成后启用。失败时先检查工具卡片的错误及网络、代理；修改媒体链接不会解决组件下载失败。

whisper.cpp：在工具详情选择并下载模型。ID 中包含 `.en` 的是英语专用模型，其他语言应选择多语言模型。界面显示模型大小和当前选中状态；只有可执行程序还不能识别。

llama.cpp：选择翻译模型，阅读界面中的许可并确认接受，再下载。当前目录提供约 2.49 GB 的 TranslateGemma 4B GGUF 模型，推理还需要额外内存。权重大小不等于内存需求，也不能用来推算速度。模型与程序发行包分别下载。

确认程序和所选模型可用后，按[字幕与翻译](subtitles.md)操作。Linux/macOS 如果需要本地识别、翻译，需自行准备兼容的可执行程序。

路径设置保存于 [Data/config.toml](../reference/configuration.md)。界面保存用于后续工作，直接编辑 TOML 后需重启 Bridge。
